# Lab 6 - Node.js Server

## Description

This project demonstrates a basic Node.js server using CORS and Nodemon.

## Commands Used

* `node server.js` — Runs the server.
* `npm i cors` — Installs CORS.
* `npm i nodemon` — Installs Nodemon.
* `npx nodemon server.js` — Runs the server with automatic restart.
* `npm run start` — Runs the start script from `package.json`.
* `rs` — Restarts Nodemon manually.
* `Ctrl + C` — Stops the server.

## Run the Project

```bash
npm install
npm run start
```

## Server

The server runs on:

```text
http://localhost:3000
```

## Technologies

* Node.js
* Express.js
* CORS
* Nodemon
